# Установка atvOS

atvOS — отдельный форк CleanYourTV с оформлением, перенесённым из проверенной сборки TCL G10 / Android 12. Это домашний экран Android TV, а не прошивка и не Apple tvOS. Телевизор не требуется рутировать или перепрошивать.

## Что понадобится

Компьютер с Git, Python 3.12, JDK 17 и Android SDK (`platforms;android-34`, `build-tools;34.0.0`). SDK можно установить через Android Studio. Укажите `JAVA_HOME` и `ANDROID_HOME` для вашей установки. Для ручной установки ниже нужны Android SDK Platform Tools (`adb`). Телевизор с Android 8+ должен быть доступен по локальной сети; включите разрешённую производителем отладку и подтвердите подключение компьютера на экране ТВ.

## Скачать и проверить исходники

```bash
git clone https://github.com/glazkov/atvOS.git
cd atvOS
```

macOS / Linux / Git Bash:

```bash
cd launcher
./gradlew --no-daemon testReleaseUnitTest lintRelease assembleRelease
cd ..
```

Windows PowerShell:

```powershell
cd launcher
.\gradlew.bat --no-daemon testReleaseUnitTest lintRelease assembleRelease
cd ..
```

Результат: `launcher/app/build/outputs/apk/release/app-release.apk`. Сборка использует локальный отладочный ключ Android; ключи владельца репозитория не публикуются. Для последующих обновлений сохраняйте тот же ключ на своём компьютере. Уже установленная сборка с другим ключом не обновится поверх: при `INSTALL_FAILED_UPDATE_INCOMPATIBLE` остановитесь и сохраните настройки прежнего лаунчера. Не удаляйте его автоматически.

## Установить и попробовать

В командах замените `192.168.1.50` на адрес своего телевизора. Если телевизор использует сопряжение Wireless debugging, сначала выполните `adb pair` с адресом, портом и кодом, показанными на ТВ, затем подключитесь к его порту подключения.

```bash
adb connect 192.168.1.50:5555
adb -s 192.168.1.50:5555 install -r launcher/app/build/outputs/apk/release/app-release.apk
adb -s 192.168.1.50:5555 shell pm grant com.gathin.tvhome android.permission.READ_TV_LISTINGS
adb -s 192.168.1.50:5555 shell am start -n com.gathin.tvhome/.MainActivity
```

Для Wireless debugging используйте актуальный порт вместо `5555` во всех командах. `READ_TV_LISTINGS` нужен полке рекомендаций: если прошивка отказывает в разрешении, обычный список приложений продолжит работать. Содержимое полки зависит от приложений и опубликованных ими рекомендаций; она не извлекает данные из закрытых аккаунтов и не гарантируется для каждого приложения. Доступ к интернету используется для обложек с адресов, предоставленных приложениями.

Сначала проверьте стрелки и OK, запуск приложений, возврат назад, настройки, HDMI и звук. Штатный домашний экран остаётся доступным. Для выбора atvOS по умолчанию откройте на телевизоре настройки приложений по умолчанию → домашний экран (путь зависит от прошивки). Не отключайте штатный лаунчер до проверки нового. Если прошивка не предлагает выбор, используйте [руководство CleanYourTV](launcher.md) и его проверку Home; не запускайте незнакомые factory/test-приложения.

## Оформление TCL

Профиль `profiles/tcl.json` переносит оформление, шесть колонок и полку из подтверждённой версии. SF Pro заменён на свободный Outfit; русские символы отображаются с системным запасным шрифтом. Приложения для просмотра, VPN, Bluetooth и назначение кнопок коллеги выбирают самостоятельно. Эти приложения не входят в atvOS.

Утилита темы заменяет существующий внешний `config.json`. Если он уже есть, сначала сохраните его:

```bash
adb -s 192.168.1.50:5555 shell content read --uri content://com.gathin.tvhome.theme/config.json > config-before-atvos.json
```

Убедитесь, что сохранён корректный JSON. Сообщение об отсутствии конфигурации означает, что внешней темы ещё нет.

macOS / Linux / Git Bash, из корня репозитория:

```bash
python3 -m venv tools/venv
tools/venv/bin/pip install -r tools/requirements.txt
mkdir -p work/atvos-theme
cp profiles/tcl.json work/atvos-theme/config.json
TV_HOST=192.168.1.50 tools/theme.sh work/atvos-theme
```

Windows PowerShell:

```powershell
python -m venv tools/venv
.\tools\venv\Scripts\python.exe -m pip install -r tools/requirements.txt
New-Item -ItemType Directory -Force work/atvos-theme
Copy-Item profiles/tcl.json work/atvos-theme/config.json
.\tools\theme.ps1 -TvHost 192.168.1.50 work/atvos-theme
```

Эти утилиты используют сетевой ADB из CleanYourTV, обычно порт 5555. При доступе только через сопряжённый Wireless debugging загрузите профиль уже подключённым `adb`:

```bash
adb -s 192.168.1.50:5555 push profiles/tcl.json /data/local/tmp/atvos-config.json
adb -s 192.168.1.50:5555 shell 'content write --uri content://com.gathin.tvhome.theme/config.json < /data/local/tmp/atvos-config.json'
adb -s 192.168.1.50:5555 shell rm /data/local/tmp/atvos-config.json
```

Подставьте свой порт. После записи перезагрузите ТВ обычным способом, чтобы лаунчер перечитал тему. Не используйте force-stop при включённых помощниках пульта: Android может отключить службу специальных возможностей.

Удержание OK на настройках открывает настройки лаунчера. Полку можно отключить ключом `"poster_shelf": false` в копии профиля и применить её снова. Новые назначения пульта и службы специальных возможностей включайте отдельно после проверки базовой работы. На некоторых TCL фильтрация кнопок мешает удержанию громкости; поэтому личные назначения владельца и включение службы в профиль не перенесены.

## Вернуться к прежнему экрану

Если штатный лаунчер оставлен включённым, выберите его в настройках домашнего экрана по умолчанию. Для возврата темы из резервной копии создайте локальную папку, положите в неё сохранённый `config.json` и примените её через `tools/theme.sh` или `tools/theme.ps1`. Сброс внешней темы к встроенным настройкам:

```bash
TV_HOST=192.168.1.50 tools/theme.sh --reset
```

Этот сброс удаляет внешнюю тему, а не восстанавливает вашу предыдущую. Если вы отдельно применяли debloat-список, восстановление описано в [restore.md](restore.md); установка atvOS по этому руководству ничего не отключает.

Когда настройка закончена, выключите отладку на телевизоре и отзовите разрешения компьютера. Домашний экран продолжит работать.

## Проверено и ограничения

Основа — подтверждённая сборка от 16 ноября 2026 года: широкие изображения 426×240 / 452×256 dp, постеры 156×234 / 180×270 dp, постоянные подписи, скрытый крупный заголовок. Более поздняя экспериментальная правка подписей не включена.

В публичной версии изменён шрифт и вынесен переносимый профиль оформления. Сборка, JVM-тесты и lint проверяются отдельно; эти проверки не заменяют проверку физического пульта и прошивки. Повторная проверка именно публичной сборки на реальном ТВ пока не выполнена. Персональные настройки, снимки, APK, ADB-ключи и резервные копии не публикуются.
